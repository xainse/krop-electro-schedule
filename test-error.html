Тест функції відображення застарілих даних

Інструкції:

  1. Відкрийте основний файл: index.html
  2. Дозвольте сторінці завантажити дані один раз (щоб зберегти їх)
  3. Відкрийте консоль браузера (F12)
  4. Виконайте один з наступних варіантів:

Варіант 1: Заблокувати запит через DevTools

  1. Відкрийте вкладку Network в DevTools
  2. Знайдіть запит до blackout.php
  3. Клікніть правою кнопкою → Block request URL
  4. Натисніть кнопку "Оновити" на сторінці

Варіант 2: Змінити URL через консоль

Виконайте в консолі браузера:

// Змінити URL на неіснуючий
API_URL = 'https://xain.in.ua/api/blackout-ERROR.php?queue=1.1';
// Потім натисніть кнопку "Оновити"

Варіант 3: Симулювати помилку через консоль

Виконайте в консолі браузера:

// Отримати поточні дані
const testData = lastSuccessfulData;
const testTime = lastSuccessfulTime;

// Очистити дані (симулювати перше завантаження)
lastSuccessfulData = null;
lastSuccessfulTime = null;

// Спробувати завантажити з неіснуючого URL
API_URL = 'https://xain.in.ua/api/blackout-ERROR.php?queue=1.1';
load();

// Після помилки - повернути дані
setTimeout(() => {
  lastSuccessfulData = testData;
  lastSuccessfulTime = testTime;
  load(); // Тепер має показати старі дані
}, 1000);

Що перевірити:

  • ✅ При помилці завантаження показуються останні успішні дані (не "невідомо")
  • ✅ З'являється червоне повідомлення про застарілі дані
  • ✅ В повідомленні вказано час останнього оновлення та вік даних
  • ✅ Текст "Останнє оновлення" стає червоним з позначкою "(застарілі)"
  • ✅ Дані зберігаються в localStorage (перезавантажте сторінку - дані мають залишитися)
