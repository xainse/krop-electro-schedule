# Changelog

Всі важливі зміни в проєкті будуть документуватися в цьому файлі.

Формат заснований на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/),
і цей проєкт дотримується [Semantic Versioning](https://semver.org/lang/uk/).

## [1.27] - 2025-11-20

### Додано
- Підтримка розпізнавання та відображення стану "Графік аварійних відключень (ГАВ)"
- Парсер тепер виявляє повідомлення про ГАВ на сайті kiroe.com.ua
- API тепер повертає поле `emergency_mode` для індикації активного ГАВ
- Відображення попередження про ГАВ з окремим емоджі ⚠️ на фронтенді
- Повідомлення про ГАВ показується в окремому блоці з помаранчевим фоном

### Змінено
- Оновлено структуру кешу для збереження стану ГАВ
- Покращено обробку стану аварійних відключень на фронтенді

## [1.26] - 2025-11-17

### Змінено
- Спрощено відображення застарілих даних: прибрано окремий рядок з повідомленням про застарілі дані
- Тепер інформація про застарілі дані відображається тільки в рядку "Останнє оновлення: хх:хх (⚠️ застарілі)"
- Покращено UX: менше тексту, більше простору на сторінці

## [1.25] - 2025-11-17

### Покращено
- Додано відображення віку застарілих даних (скільки хвилин тому було останнє оновлення)
- Покращено обробку помилок парсингу JSON - тепер також показуються старі дані при помилці
- Покращено повідомлення про застарілі дані - додано детальну інформацію про час останнього оновлення

## [1.24] - 2025-11-17

### Додано
- При помилці завантаження даних з API тепер відображаються останні успішно завантажені дані замість невідомих значень
- Червоне повідомлення про застарілі дані з часом останнього успішного оновлення
- Збереження останніх успішних даних в localStorage для використання при перезавантаженні сторінки
- Відображення збережених даних при першому завантаженні сторінки

### Змінено
- При помилці API дані не скидаються до невідомих значень, а залишаються останні доступні
- Текст "Останнє оновлення" стає червоним при відображенні застарілих даних

## [1.23] - 2025-11-17

### Змінено
- Видалено використання CORS proxy (corsproxy.io) - тепер API викликається напряму
- Додано CORS заголовки в PHP API для дозволу прямого виклику з браузера
- Спрощено код завантаження даних - прибрано функцію `fetchWithProxy()`

## [1.22] - 2025-11-14

### Додано
- Система логування всіх запитів до API в файли `api/logs/blackout_YYYY-MM-DD.log`
- Відстеження швидкості відповіді (час виконання в мілісекундах)
- Відстеження джерела даних (кеш або сайт) для кожного запиту
- Логування IP адреси клієнта та User-Agent
- Автоматична ротація логів (один файл на день)

### Змінено
- Додано функції для логування: `getLogPath()`, `getClientIp()`, `logRequest()`
- Всі запити (успішні та помилки) тепер логуються в JSON форматі

## [1.21] - 2025-11-14

### Додано
- Система кешування даних на 10 хвилин у файлі `api/cache/blackout_cache.json`
- Автоматичне створення папки cache та файлу кешу
- Парсинг всіх черг з HTML при оновленні кешу для зменшення навантаження на джерело

### Змінено
- Оптимізовано роботу API: тепер дані завантажуються з сайту тільки якщо кеш застарів або відсутній
- Додано функції для роботи з кешем: `getCachePath()`, `isCacheValid()`, `loadCache()`, `saveCache()`, `parseAllQueues()`
