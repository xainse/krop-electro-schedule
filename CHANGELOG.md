# Changelog

Історія попередніх версій доступна в [`docs/CHANGELOG.md`](docs/CHANGELOG.md).

## [Unreleased]

## [5.8] - 2026-11-08

### Змінено
- Об’єднано підтримку графіків за датою з оновленнями залежностей і документації з `main`.

## [5.7] - 2026-11-08

### Додано
- Параметр API `date=DD.MM.YYYY` для отримання збережених графіків за певну дату та документацію API.

### Змінено
- Збережені графіки за минулі дні більше не видаляються; графіки, отримані з резервного сайту, зберігаються за своєю датою.
- Для запитів на інші дати уточнено відповіді за відсутності графіка або черги та значення `stale`.
