# Changelog

Всі важливі зміни в проєкті будуть документуватися в цьому файлі.

Формат заснований на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/),
і цей проєкт дотримується [Semantic Versioning](https://semver.org/lang/uk/).

## [1.10] - 2025-01-10

### Виправлено
- Виправлено алгоритм парсингу діапазонів годин з API
- Дозволено значення до 24 для діапазонів типу "22-24"
- Змінено цикл з `h <= end` на `h < end` для правильного парсингу
- Додано перевірку `h < 24` для безпеки

## [1.9] - 2025-01-10

### Додано
- Додано browser notifications при зміні графіку
- Додано запит дозволу на нотифікації при завантаженні сторінки
- Додано футер зі статусом нотифікацій (англійською)
- Додано збереження статусу нотифікацій в localStorage
- Винесено CSS стилі в окремий файл `styles.css`
