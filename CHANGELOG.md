# Changelog

Всі важливі зміни в проєкті будуть документуватися в цьому файлі.

Формат заснований на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/),
і цей проєкт дотримується [Semantic Versioning](https://semver.org/lang/uk/).

## [1.31] - 2025-01-10

### Змінено
- Змінено орієнтацію таблиці всіх черг: черги тепер по вертикалі (ліворуч), години по горизонталі
- Прибрано заголовки часу з таблиці - виводяться тільки заголовки черг
- Додано виділення стовпчика з активною годиною (синя рамка)
- Зменшено розмір ячеек на 30% для кращої компактності (28px замість 40px)

## [1.30] - 2025-01-10

### Додано
- Таблиця всіх черг нижче банера донації: візуалізація графіків відключень для всіх 12 черг одночасно
- По горизонталі відображаються черги (1.1-6.2), по вертикалі - години (0-23)
- Квадратні ячейки без тексту, зафарбовані тими ж кольорами що і на головному екрані
- Підтримка півгодинних періодів у таблиці (градієнти для змішаних станів)
- API endpoint `?all=1` для отримання даних всіх черг одночасно
- Автоматичне оновлення таблиці при оновленні даних з серверу

### Змінено
- API тепер підтримує параметр `all=1` для повернення даних всіх черг з кешу

## [1.29] - 2025-01-10

### Додано
- Перевірка на скасування ГАВ: парсер тепер виявляє текст "дію графіка аварійних відключень (ГАВ) скасовано" і автоматично встановлює `emergency_mode = false`
- Підтримка використання кешу при ГАВ: якщо графіки не оновлені на сайті, використовуються графіки з кешу

### Виправлено
- Кеш більше не видаляється, поки не отримані нові дані з сайту
- При недоступності сайту (kiroe.com.ua не працює) API використовує дані з кешу замість повернення помилки
- Фронтенд завжди отримує дані (з кешу або з сайту), навіть якщо сайт недоступний

### Змінено
- Покращено логіку кешування: кеш завжди завантажується якщо він існує, незалежно від TTL
- Оптимізовано обробку помилок: при будь-якій помилці парсингу використовується кеш якщо він доступний

## [1.28] - 2025-11-20

- Графік тепер завжди відображається навіть при активному ГАВ, надаючи користувачам орієнтовну інформацію
