## Перевірки

- Базова версія: Jest 66/66, PHPUnit 73/73.
- Поточна перевірка: Jest 80/80, PHPUnit 83/83 (191 assertions), TypeScript — без помилок.
- Ручна локальна перевірка Chrome: прострочений кеш не показує світло чи відключення, зміна 1.1 → 6.2, видима версія 4.1, заголовки/описи таблиці.
- Mobile 375×812: `documentElement.scrollWidth === innerWidth === 375`, горизонтального переповнення сторінки немає.
- Playwright: **не пройдено через середовище**. Автозапуск PHP обмежено `Operation not permitted`; з окремим дозволеним сервером Chrome завершується `SIGABRT/EPERM` до виконання assertions усіх 10 сценаріїв. Це не успішний E2E результат.

## Що ще потрібно для завершення

- Пройти Playwright у середовищі, де дозволено запуск test browser і локальні з'єднання.
- Визначити наявний FTP/SFTP/SSH доступ та document root xain.in.ua; налаштувань деплою в проєкті немає.
- Після тестів: коміт, push, деплой API й перевірка GitHub Pages.
- Перевірити HTTP методи, CORS і заборону runtime шляхів на production після деплою. Наявність ризику визначено за кодом, доступність службових файлів на поточному production не підтверджена.
- Закрити issues лише після публікації й smoke перевірок.

Прямий curl/git read у поточному shell не резолвить зовнішні домени. GitHub connector працює: через нього створено всі сім issues. Browser показав реальні API JSON у console logs сторінки. Пряму навігацію до production API browser tool заблокував; це не доказ недоступності API для користувачів.

## Повторний запуск користувача, 09:55

Звіт Playwright `http://127.0.0.1:9323/` показав 8 passed / 2 failed. Обидві помилки — `Test not found in the worker process. Make sure test title does not change.` у параметризованих `malformed payload` сценаріях. Причина: назва містила JSON із `Date.now()`; discovery та worker отримували різні ідентифікатори.

Назви замінено на сталі `API error` і `invalid time range`; runtime timestamp залишився лише в даних відповіді. Перевірка discovery з двома різними значеннями Date.now повернула тотожний список усіх 10 тестів. Jest 80/80 і TypeScript пройшли повторно. Повторний повний запуск із sandbox зупиняється на bind порту 8080 (`Operation not permitted`); успішний E2E після цієї правки ще не підтверджено.
