## 🔄 ЩО БУДЕ ПРАЦЮВАТИ ПІСЛЯ НАЛАШТУВАННЯ

### Автоматичний процес:
```
1. Нове повідомлення в Telegram каналі
   ↓
2. Telegram надсилає webhook на твій сервер
   ↓
3. telegram_webhook.php обробляє повідомлення
   ↓
4. parser.php парсить графік
   ↓
5. data.php зберігає в schedules.json
   ↓
6. Користувач відкриває сайт
   ↓
7. blackout_new.php читає з кешу
   ↓
8. Моментальна відповідь!
```

### Fallback при збоях:
```
Кеш порожній/застарілий?
   ↓
Пробуємо Telegram API
   ↓ (якщо не вдалося)
Пробуємо kiroe.com.ua
   ↓ (якщо не вдалося)
Повертаємо помилку
```
