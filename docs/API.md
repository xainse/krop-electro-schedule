# Як отримати графік на інший день

Базова адреса:

```
https://xain.in.ua/api/blackout.php
```

Метод: `GET`. Дата в параметрі `date` має формат `DD.MM.YYYY` і рахується за часовим поясом Europe/Kyiv.

Без `date` API віддає графік на сьогодні. Завтрашній або минулий день потрібно запитати явно. Такий запит не замінює сьогоднішній графік.

## Запити

Одна черга на сьогодні:

```
https://xain.in.ua/api/blackout.php?queue=1.1
```

Та сама черга на конкретний день:

```
https://xain.in.ua/api/blackout.php?queue=1.1&date=05.11.2026
```

Усі черги на цей день:

```
https://xain.in.ua/api/blackout.php?all=1&date=05.11.2026
```

Черги: `1.1`, `1.2`, `2.1`, `2.2`, `3.1`, `3.2`, `4.1`, `4.2`, `5.1`, `5.2`, `6.1`, `6.2`.

Графік на завтра з’являється лише після того, як його опублікували в Telegram-каналі або на сайті і сервер встиг його прочитати. Читання джерел іде разом із перевіркою сьогоднішнього графіка, не частіше ніж раз на 5 хвилин. Окремий запит на завтра канал сам не відкриває.

Минулий день доступний, якщо цей графік уже збережено. Дні, стерті до появи цього параметра, повернути не можна. Нові дні накопичуються далі.

## Як читати відповідь

Успішний графік, HTTP 200:

```json
{
  "success": true,
  "date": "05.11.2026",
  "available": true,
  "schedule": "02:00-04:00, 18:00-20:00",
  "not_announced": false,
  "message": null
}
```

`schedule` — інтервали відключення. Порожній рядок `""` означає, що джерело прямо повідомило про відсутність планових відключень. `null` означає, що даних для цієї черги немає.

Якщо графіка на майбутній день ще немає, HTTP 200:

```json
{
  "success": true,
  "date": "05.11.2026",
  "available": false,
  "schedule": null,
  "not_announced": false,
  "updated": null,
  "message": "Графік на 05.11.2026 ще не опубліковано"
}
```

Якщо минулого дня в архіві немає, HTTP 200 і `message`: `Немає збереженого графіка на DD.MM.YYYY`.

Якщо день є, а цієї черги в ньому немає: `Немає даних для черги 1.1 на DD.MM.YYYY`.

`not_announced: true` стосується лише сьогодні, коли джерело прямо написало, що графіка на сьогодні немає. Для іншого дня відсутність запису не є таким повідомленням.

`stale: false` у минулого збереженого дня означає, що це зафіксований графік. У майбутнього дня `stale: true` означає, що перевірка старша за 10 хвилин; сам графік у відповіді лишається.

Неіснуюча або неправильно записана дата дає HTTP 400:

```json
{
  "success": false,
  "error": "Invalid date. Expected DD.MM.YYYY"
}
```

Для сьогодні, якщо немає ні кешу, ні джерел, відповідь може бути HTTP 503. Для іншої валідної дати відсутність запису лишається HTTP 200.
