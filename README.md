# ⚡ Графік відключень електрики — черга 1.1

Веб-додаток для відображення графіку відключень електрики на 24 години для черги 1.1.

## 📋 Опис

Цей проєкт показує візуальний графік стану електрики протягом доби. Кожна година відображається окремою клітинкою:
- ⚡ **Жовта клітинка** — електрика є
- 🌑 **Темна клітинка** — електрика відключена

## 🚀 Функціонал

- 📊 Візуалізація графіку на 24 години
- 🔄 Автоматичне оновлення даних з API
- 🌐 Обхід CORS обмежень через проксі-сервіс
- 📱 Адаптивний дизайн для мобільних пристроїв
- ♿ Підтримка доступності (screen readers)

## 🛠 Технології

- Чистий HTML/CSS/JavaScript
- Fetch API для отримання даних
- CORS proxy для обходу обмежень браузера

## 📡 API

Додаток отримує дані з API:
```
https://gordovoy.net/blackout.php?queue=1.1
```

Формат відповіді: JSON з полем `schedule`, що містить діапазони годин відключення у форматі:
```json
{
  "schedule": "02-04, 06-08, 10-13, 14-16, 18-20, 22-24"
}
```

## 🎨 Використання

1. Відкрийте `index.html` у браузері
2. Додаток автоматично завантажить дані з API
3. Натисніть кнопку "🔄 Оновити" для ручного оновлення
